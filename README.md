# המתכונים שלי

ספרייה של סרטוני מתכונים: רואים מתכון באינסטגרם, בפייסבוק, בטיקטוק או ביוטיוב,
מעתיקים קישור, ושומרים אותו כאן בקטגוריה. **הקישור נשמר, לא הסרטון** — הצפייה
נעשית מול הפלטפורמה, בנגן בתוך האפליקציה או בפתיחה שם.

<https://lironcon2015-prog.github.io/Recipes/>

הלוגיקה (קישור, תצוגה מקדימה, תמונות, נגינה, סנכרון) הועתקה מספריית הסרטונים של
[nines](https://github.com/lironcon2015-prog/nines) — ההסבר המלא לכל החלטה שם,
בפרק "ספריית הסרטונים" ב-README. העיצוב בשפה של
[MGivatayim](https://github.com/lironcon2015-prog/MGivatayim).

## מה יש

- **הוספה בשתי נגיעות** — "מתכון" ← "הדבק" ← "שמירה". השם והתמונה נמשכים מהקישור.
  באנדרואיד, אחרי התקנה: "שיתוף" מאינסטגרם ישר לאפליקציה.
- **קטגוריות שאתה יוצר** — הוספה, שינוי שם, מחיקה וגרירה לשינוי הסדר (תגית
  "ניהול" בסוף שורת הקטגוריות). מחיקה לא מוחקת מתכונים. קטגוריה חדשה גם מתוך
  טופס ההוספה ("+ חדשה").
- **חיפוש** בשם, בהערה ובקטגוריה.
- **שתי תצוגות** — רשת של תמונות לאורך, או אזור לכל קטגוריה (המתג ליד הכותרת).
- **נגן מעל הדף**, עם ההערה שלך ו"פתיחה באינסטגרם".
- **סנכרון לדרייב** (לא חובה) — ראו `apps-script/README.md`.
- **עובד בלי רשת**, חוץ מהנגינה עצמה.

## הקבצים

```
index.html            המעטפת
css/app.css           העיצוב (שפת גבעתיים)
js/app.js             ניתוב ואתחול: #/  #/c  #/s  #/join/…
js/library.js         המסך הראשי, גיליון ההוספה, הנגן, השלמת תמונות
js/categories.js      ניהול הקטגוריות
js/sync.js            מנוע הסנכרון ומסך ההגדרות
js/ui.js              רכיבים משותפים: גיליון, שכבות ו"חזרה", הודעה קופצת
js/videos.js          הנתונים, המיזוג, זיהוי פלטפורמה ושיבוץ   (מ-nines)
js/preview.js         שם ותמונה מהקישור                        (מ-nines)
js/posters.js         התמונות ב-IndexedDB                      (מ-nines)
js/cloud.js           הלקוח מול הסקריפט בדרייב                 (מ-nines)
js/version.js         מספר הגרסה שמוצג
sw.js                 מטמון לעבודה בלי רשת
apps-script/Code.gs   הסקריפט לדרייב
tools-check.mjs       בדיקה לפני פרסום
```

## פריסה

GitHub Pages מענף `main`, שורש הריפו. דחיפה ל-`main` היא הפריסה.
בכל שינוי קוד: העלאת `VERSION` ב-`sw.js` **ו**ב-`js/version.js`, ואז
`node tools-check.mjs`.
